Pulse — User Guide & Help

🚀 3-Step Quick Start

1
Get your API Key:

Create or copy your key from the official AgentRouter Token Console.

2
Enter & Save Key:

Click Enter Key at top or open Settings (⚙️). Paste your key and click Save Key. It is encrypted at rest using Windows DPAPI and never saved in plaintext.

3
Monitor Real-Time Quotas:

Select any model (e.g. Claude 3.5 Sonnet or DeepSeek V4 Flash) and click Test Connection. Keep Pulse docked while coding in Cursor or VS Code!

⏱️ Daily Quota Release Schedule

AgentRouter allocates Claude & GPT pool quotas twice daily at exact fixed intervals:

Batch 1 (Morning) 10:00 CST (Beijing) 02:00 UTC 07:30 AM IST (India)
Batch 2 (Evening) 19:00 CST (Beijing) 11:00 UTC 04:30 PM IST (India)

💡 The countdown timer on your screen shows the exact time remaining until the next release. If audio notifications (🔔) are enabled, a discreet chime rings at 00:00:00.

⚡ Quota Pool vs. Uninterrupted Models

Quota Pool Models (Claude & OpenAI)

Claude 3.5 Sonnet, Claude 3.7 Thinking, Claude Opus 5, GPT-4o, and GPT-6 Astra draw from the shared daily allocation. When depleted, you will see HTTP 402 Budget Pool Quota Exhausted.

⚡ Uninterrupted Models (Zero Pool Lock)

DeepSeek V4 Flash, DeepSeek Chat (V3), DeepSeek Reasoner (R1), and GLM-4 Plus are NOT bound to daily quota limits! You can switch to them anytime for uninterrupted work.

🛠️ Status Code Diagnostic Reference

  • 200 OK Available & Active: Model is online and ready for API requests.
  • 402 Budget Pool Exhausted: Daily quota ran out. Wait for next drop or switch to DeepSeek V4 Flash.
  • 503 No Channel: The model is not mapped to your key's current channel group. Click Discover or pick DeepSeek V4 Flash.
  • 401 Unauthorized: Invalid API key or blocked client identity. Pulse includes allowlisted headers automatically.
  • 0 / Offline Connection Error: Check your internet connection or verify https://agentrouter.org status.
